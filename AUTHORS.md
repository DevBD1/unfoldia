# Unfoldia contributors

Initiated by **Burak (DevBD1)**, with room for a global community of educators,
learners, translators, subject reviewers, designers, and developers.

Git history and merged pull requests record code and documentation contributions.
For non-code work, contributors may request credit in this file through a PR,
using their preferred public name and a short description of the contribution.
Only add names with permission; do not infer identities or list future contributors.

The original Burak copyright notice remains in [LICENSE](LICENSE). Unfoldia is
the project identity, not a replacement legal owner of existing work.
